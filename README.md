## 🎯 Sobre o projeto

Plataforma web **premium, mobile-first** para a **ABD, Lda** — oficina sénior especializada em:

- 🛠️ Chaparia de precisão
- 🎨 Pintura em estufa com certificação de cor
- ⚙️ Mecânica geral e pesada
- 💻 Diagnóstico eletrónico multimarca
- 🔧 Caixa de velocidades automáticas
- ✨ Detalhe automóvel

Servindo **proprietários de viaturas de luxo** (Mercedes-Benz, BMW, Range Rover, Porsche, Audi, Lexus, Toyota) e **gestores de frotas corporativas/executivas**.

## 🗺️ Roadmap da Plataforma Completa

O projeto completo (a entregar após aprovação) contempla **3 grandes módulos**:

### 1️⃣ Portal Público *(este preview)*
- Landing institucional
- Consulta pública por matrícula
- Agendamento em etapas
- Geolocalização + contactos diretos

### 2️⃣ Área do Cliente *(login)*
- 🚗 Garagem Digital (veículos vinculados)
- 📋 Histórico Clínico com relatórios PDF
- ✅ Aprovação de orçamentos em 1 clique
- 📸 Galeria de progresso da reparação

### 3️⃣ Backoffice da Oficina
- 🗂️ Kanban de oficina (Receção → Concluído)
- 📥 Check-in digital com fotos de todos os ângulos
- 🧾 Gestão de Ordens de Serviço e mecânicos
- 🏢 Dashboard dedicado a Frotas (B2B)

### 💎 Diferenciais Premium
- 📲 **Notificações automáticas via WhatsApp Business API** a cada mudança de estado
- 🔐 **Passaporte Digital de Manutenção** com QR Code no veículo
- 🚙 **Módulo Concierge LEVA-E-TRAZ** — recolha e entrega com rastreio

## ⚙️ Stack Técnica Recomendada

```
Frontend   →  Next.js 14 (App Router) + TypeScript + Tailwind CSS + Framer Motion
Backend    →  NestJS + Prisma ORM + PostgreSQL
Integrações→  WhatsApp Business API · Google Maps · E-mail transacional
Infra      →  Vercel (web) · Railway/Fly.io (API) · Supabase/Neon (BD)
```

## 🚀 Como testar este preview

### Opção A — Local (1 clique)
```bash
git clone https://github.com/<seu-user>/abd-oficina-preview.git
cd abd-oficina-preview
# Abra index.html no browser
open index.html      # macOS
start index.html     # Windows
xdg-open index.html  # Linux
```

### Opção B — GitHub Pages
1. Faça push deste repositório para o GitHub
2. Vá em **Settings → Pages**
3. Selecione **Branch: `main`** / **Folder: `/ (root)`**
4. Aceda a `https://<seu-user>.github.io/abd-oficina-preview/`
